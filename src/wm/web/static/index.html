    Setup & Pipeline

    System status and pipeline commands

    Run the full pipeline

    1
    Install & Ingest pip install -e .
    wm ingest --source results

    Downloads ~48k international matches (1872–present) from GitHub. Free, no auth needed.

    2
    Optional: Player Ratings wm ingest --source players

    Download EA FC ratings from Kaggle and save to data/raw/players/ea_fc_ratings.csv

    3
    Build Features wm build-features

    Computes Elo, form windows, travel/altitude/weather context — leak-free.

    4
    Train Models wm train

    LightGBM W/D/L classifier + Poisson goal regressors + calibration.

    5
    Simulate Tournament wm simulate --runs 100000

    Run 100k Monte Carlo tournaments. Or click the button in the 🏆 Odds tab for a quick 10k run.

    6
    Serve this UI wm serve --port 8000

    Open localhost:8000 in your browser.
